# Чайка Обеды

Адаптивная вёрстка сервиса доставки готовых обедов для Ялты, Севастополя и Симферополя. Next.js, React, TypeScript и обычный CSS. Шрифты, логотип и фотографии хранятся в проекте.

## Открыть сайт

Требуется Node.js 22 LTS и npm. Версия также указана в `.nvmrc`.

```bash
npm install
npm run dev
```

Откройте http://127.0.0.1:3000. Чтобы остановить сервер, нажмите Ctrl+C в терминале.

## Заменить логотип

Замените **`public/brand/logo.png`** своим PNG-файлом с таким же именем. Лучше использовать изображение с прозрачным фоном без больших пустых полей. Сейчас здесь лежит исходный CHAIKATEAM, предоставленный вами.

Обновите страницу. Если браузер показывает старую картинку, выполните обновление без кеша. Другой путь или формат логотипа можно указать в `src/data/site.ts` в поле `logo`. Размеры логотипа на компьютере и телефоне задаются селектором `.logo` в `src/app/globals.css`.

## Возможности

- Двенадцать комплектов по 450–550 ₽, подробный состав и аллергены.
- Своё меню на каждый будний день: по 2–3 комплекта без повторов в течение недели. В недельном выборе — только блюда соответствующего дня.
- Выбор из пяти ближайших рабочих дней и сбор заказа на несколько дней.
- Корзина с количеством и сохранением в браузере после обновления страницы.
- Выбор города и адреса, демонстрационное оформление и подтверждение.
- Предварительный расчёт обедов для команды.
- Мобильная корзина, адаптивные формы, управление диалогами с клавиатуры.
- Одна выпечка бесплатно при заказе на все пять ближайших рабочих дней. Подарок появляется автоматически, сохраняется при обновлении и исчезает, если убрать один из дней. Количество порций на один день не влияет на это условие. Подарок не увеличивает цену или стоимость доставки.

## Меню по дням

| День | Комплекты |
| --- | --- |
| Понедельник | Домашний, Классический, Особенный |
| Вторник | Индейка с булгуром, Тефтели с пастой, Жаркое с картофелем |
| Среда | Плов с курицей, Рыба с кускусом |
| Четверг | Котлеты с пюре, Бефстроганов с рисом |
| Пятница | Фаршированные перцы, Курица с грибами |

Расписание повторяется каждую неделю. Редактируйте `weeklyMenu` в `src/data/menu.ts`: ключи 1–5 соответствуют понедельнику–пятнице, значения — идентификаторам обедов. При изменении меню ранее сохранённые позиции, недоступные на свою дату, исключаются из корзины.

Фотография подарка — `public/images/weekly-gift.png`, предоставленная вами. Название и изображение можно поменять в `site.weeklyGift`. Текущая механика — одна выпечка на весь недельный заказ, включая коллективный; размер подарка для групп можно изменить отдельно.

## Границы демонстрации

Заказы и заявки **никуда не отправляются**, оплата не производится. Персональные данные используются только в открытой вкладке; в localStorage сохраняются только позиции корзины. Флаг `demo` в настройках сам по себе не подключает рабочий приём заказов.

Меню, состав, вес и фотографии иллюстративные. Перед публикацией замените их на реальные данные кухни. Доставка 100 ₽ за каждый день заказа и интервалы указаны для примера. Реальные зоны, расписание, доступность блюд и тарифы пока не проверяются сервером. Пять ближайших рабочих дней рассчитываются в часовом поясе Крыма; ограничение приёма заказов по времени ещё не подключено.

Для запуска необходимо подключить сервер заказов и оплату, заменить примерные условия и контакты, добавить необходимые документы. Индексирование поисковиками пока отключено через `robots` в `src/app/layout.tsx`.

## Сборка для хостинга

```bash
npm run build
```

Готовый статический сайт появляется в **`out/`**. Содержимое этой папки можно загрузить на хостинг статических сайтов. После изменения исходников или логотипа сборку нужно повторить.

Для локального просмотра сборки сначала остановите сервер разработки, затем:

```bash
npm run preview
```

## Timeweb App Platform

Параметры для размещения: тип **Frontend**, фреймворк **Next.js**, Node.js **22**, SSR выключен, ветка `main`, команда сборки `npm run build`, директория публикации `out`. Переменные окружения и команда запуска не требуются. Автодеплой выключен: обновления публикуются вручную из панели Timeweb.

Исходники приложения хранятся в Git. Папки `research`, `node_modules`, `.next`, `out`, результаты тестов и локальные секреты исключены из репозитория. После изменения логотипа или меню сохраните изменения в Git, отправьте их в репозиторий и запустите новый деплой в Timeweb.

## Проверки

```bash
npm run typecheck
npm run lint
npx playwright install chromium
npm run test:e2e
```

Тесты проверяют покупательский сценарий, расчёты, сохранение корзины, ассортимент по дням, выдачу и отмену подарка, выбор города, клавиатурное управление и узкий экран. Они запускаются в Chromium для компьютера и с параметрами мобильного устройства.

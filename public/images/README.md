# Изображения блюд

Двенадцать иллюстративных фото обедов созданы встроенным image_gen для вёрстки. Перед коммерческим запуском замените их фотографиями ваших блюд. Сохраняйте имена файлов или меняйте пути в src/data/menu.ts.

Промпты девяти новых обедов и имена файлов: [weekly-menu-prompts.md](weekly-menu-prompts.md).

`weekly-gift.png` — оригинальное изображение выпечки, предоставленное пользователем; не генерировалось и не редактировалось.
